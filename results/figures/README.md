# Figures and supplementary tables

- fig2a_primer_map.{pdf,png,svg} – Figure 2A (`scripts/fig_primer_map.py`): LAMP primer binding sites on the uidA and papGII
  amplicons; median mismatches to the primer per binding site, per Clermont phylogroup (uidA) and per papG class (papGII),
  shown separately for the UPEC collection (n = 738) and the NCBI RefSeq complete genomes (n = 5,493)
- fig2a_binding_sites.tsv – binding-site coordinates (amplicon coordinates, 1-based), role, orientation, sequence, and
  mismatches of the papGII sites to the PapG-I/II/III reference alleles
- fig2a_uidA_phylogroup_median_mismatches_{upec,ncbi}.tsv – values shown in the uidA rows (+ n genomes per phylogroup)
- fig2a_papG_allele_median_mismatches_{upec,ncbi}.tsv – values shown in the papGII rows (+ n genomes per papG class)
- tableS_binding_site_mismatches.tsv – UPEC collection, per target and site: genomes with 0, 1, 2, >= 3 mismatches to the
  primer and with a mismatch in the 3'-terminal 5 nt (`scripts/tables_s_primer_conservation.py`; descriptive only)
- tableS_binding_site_presence.tsv – papGII binding sites present per papG group (UPEC collection)
