# Gene-wide variability (UPEC collection)

`uidA/` (738 genomes) and `papGII/` (the 140 genomes typed papGII): per-position variability of the reference gene of
E. coli 700223-20, and the amplicon and binding sites in gene coordinates (`scripts/gene_scan.py`). Each subfolder has its
own README with the column definitions; papGII_genomes.txt lists the genomes included in the papGII scan.
